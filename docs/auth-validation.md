# Authentication Validation Notes

The unauthenticated root route now opens the ORBIT local account screen directly. It contains only the **Вход** and **Регистрация** modes, a username field, a password field, a password-visibility control, and the registration password confirmation field. The public view no longer exposes an e-mail address, the former landing-page CTA, or a Google sign-in control.

The dashboard’s local profile label has been changed from the user e-mail to **Личный аккаунт**. Any fixed platform controls visible at the very bottom of the development preview are runtime preview chrome rather than elements emitted by the ORBIT application source.
