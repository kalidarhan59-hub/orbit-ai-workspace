# Публикация ORBIT через GitHub

GitHub-репозиторий ORBIT доступен по адресу `https://github.com/kalidarhan59-hub/orbit-ai-workspace`.

Рабочее приложение с AI, авторизацией, базой данных, историей, файлами и Voice Chat опубликовано на Manus:

`https://orbitai-puwn5ge3.manus.space`

Корневой `index.html` GitHub Pages автоматически перенаправляет посетителя на этот Manus URL. GitHub Pages используется только как публичная точка перехода и хранилище исходного кода.

> GitHub Pages не запускает backend ORBIT, базу данных, серверную авторизацию или AI API. Поэтому рабочий Chat открывается на Manus, а не исполняется внутри GitHub Pages.

Если браузер показывает старую версию README, это означает, что GitHub Pages или браузер ещё использует кэш. Обновите страницу с очисткой кэша или откройте URL в приватном окне. Прямой рабочий адрес Manus всегда остаётся актуальным.
