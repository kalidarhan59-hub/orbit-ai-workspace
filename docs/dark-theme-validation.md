# Dark Theme Validation

## Restarted desktop preview inspection

The restarted `/app` preview was inspected at **1440 × 900**. The document root, sidebar, workspace background, chat panel, context column, composer, and all visible cards rendered in dark navy/graphite surfaces. No white outer shell was visible.

Foreground text remained readable: headings use near-white, body copy uses muted slate on dark surfaces, and violet/cyan accents remain distinguishable. The sidebar, three-column workspace, context cards, and composer all fit within the viewport without horizontal clipping or overlap.

The standalone **Сайт** control was absent. The composer exposes only **Intelligence** and **Изображение** modes, while the welcome card provides **Написать код** as a normal chat request.
